# Admin UI

This directory will contain the Admin UI for story authoring (Spec §8).

Planned screens:
- Draft Story List
- Story Brief Form
- Story Graph View (Mermaid / React Flow / SVG)
- Node Detail Panel
- Simulation View

For the MVP skeleton, the API endpoints in `app/api/admin_story_draft_routes.py`
are the primary interface. A simple HTML frontend can be added later.
